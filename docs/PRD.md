## 1. 产品概述

### 1.1 一句话定位
从「一个想法」或「一本小说」出发，一路生成**策划案 → 集纲 → 互动影视剧本**的短剧创作工作台。**互动影视剧本是差异化重点。**

### 1.2 主链路

```
           ┌─ 原创模式（默认） ─┐         ┌─ 一句话生成 ─┐
首页 ──────┤                    ├──选择──┤              ├──→ 策划案 ──→【集纲生成弹窗】
           └─ 小说改编模式 ─────┘         └─ 精细生成 ───┘                 │
                 （可切换）               （风格/类型/市场/Skill）          │
                                                                ┌────────────┴────────────┐
                                                          ① 直接生成全部集纲      ② 分卡点输出集纲
                                                                │                 （滑动选卡点集数）
                                                                │                 一卡 / 二卡 / 三卡
                                                                └────────────┬────────────┘
                                                                             ↓
                                                                【转互动影视剧本】（每个入口都可以转）
                                                                             ↓
                                                             分支节点编辑 → 校验 → 导出
（暂定）爆款对标模式：上传爆款剧本 → 拆解 → 本土化 / 出海改写 → 并入上述链路
```

### 1.3 目标用户
| 用户 | 诉求 |
|------|------|
| 短剧编剧 / 编剧工作室 | 提效：快速出策划、集纲，保留精修空间 |
| 网文作者 / IP 方 | 把小说低成本改编成短剧或互动剧 |
| 短剧制片 / 出品方 | 批量立项、对标爆款、评估、出海 |
| 互动影视 / 游戏化内容团队 | 生成带分支、选项、多结局的可执行剧本 |

| **小云雀（剧本创作）** | 剧本创作 | 【待补充截图结论】 | — |

**差异化**：
1. 竞品大多停在「剧本 / 集纲」，我们把**互动影视剧本**作为一等产物。它从集纲直接转，支持分支、数值、多结局和付费节点。
2. **卡点驱动的集纲**：按商业化付费卡点（一卡、二卡、三卡）切段生成，贴合短剧行业的写法。
3. **Skill 可插拔**：内置和用户上传的 Skill 都能挂到生成流程上，团队方法论可以复用。

## 4. 功能需求

优先级：**P0** = MVP 必须，**P1** = 第二期，**P2** = 规划中。

### 4.1 首页与模式切换（P0）
- 进入首页默认选中**原创模式**，可切换为**小说改编**。切换时保留已填的通用参数（风格、类型、市场），清空模式专属输入并给出提示。
- 每个模式下二选一：**一句话生成** / **精细生成**，默认一句话生成。
- 首页展示：模式说明、示例灵感（点击填入）、最近项目。

### 4.2 原创模式
| 方式 | 输入 | 说明 |
|------|------|------|
| 一句话生成 | 一句话创意（≤200 字）+ 可选：风格、类型、目标市场 | 其余参数由系统按市场给默认值，适合快速出稿 |
| 精细生成 | 一句话创意 + 下表全部参数 + Skill | 适合专业编剧 |

**精细生成参数**：
| 参数 | 选项（示例） | 必填 |
|------|-------------|-----|
| 类型 / 题材 | 都市、甜宠、复仇、战神、赘婿、重生、穿越、玄幻、悬疑、家庭伦理、霸总、萌宝、年代…（多选 ≤3） | 是 |
| 风格 | 爽感、虐恋、轻喜、暗黑、热血、治愈、反转密集… | 是 |
| 目标市场 | 国内（抖音 / 快手 / 红果 / 小程序）、北美、东南亚、日韩、中东、拉美…【待确认清单】 | 是 |
| 语言 | 跟随市场默认，可改 | 否 |
| 总集数 / 单集时长 | 默认国内 80 集 × 1–2 分钟，海外 60 集【待确认】 | 是 |
| 主角设定 | 性别、身份、金手指、人设关键词 | 否 |
| 受众 | 男频 / 女频 / 全年龄 | 否 |
| 参考作品 | 文本输入或选爆款库 | 否 |
| Skill | 见 §4.4 | 否 |

### 4.3 小说改编模式
| 方式 | 输入 | 说明 |
|------|------|------|
| 一句话生成 | 上传小说（txt / docx / epub）或粘贴文本 + 一句话改编方向 | 自动解析后直接出策划案 |
| 精细生成 | 上传小说 + 改编参数 + Skill | 先出**小说解析总览**，确认后再出策划案 |

- **小说解析总览（P0）**：章节列表、主要人物关系、主线、核心爽点和名场面、建议截取的章节范围。用户可以勾选改编的章节范围。
- **改编参数**：改编力度（忠于原著 / 适度改编 / 大幅重构）、保留人物、删减支线、在原参数之外加上风格、类型、市场、集数。
- **字数限制**：单本 ≤ 200 万字【待确认】；超长时提示分卷导入。
- **版权声明**：上传前勾选「本人拥有改编权或已获授权」。

### 4.4 Skill 体系（精细生成，P0 内置 + P1 上传）
- **定义**：Skill 是一份可复用的创作方法论，包含提示词、规则、范例和输出格式，可以挂载到生成环节。
- **内置 Skill（示例）**：黄金三秒开篇、爽点密度控制、反转设计、付费卡点钩子、海外本土化（文化与禁忌）、人物弧光、台词口语化、互动分支设计。
- **用户 Skill**：上传 Markdown / 文本，支持示例文件。填写名称、描述、**适用环节**（策划案 / 集纲 / 互动剧本 / 全部）。
- **挂载规则**：每次生成最多挂 5 个；同一环节多个 Skill 冲突时，按用户排序的优先级执行；生成结果要标注用了哪些 Skill。
- **可见性**：私有 / 团队共享 / 公开（P2，需要审核）。

### 4.5 策划案（P0）
生成后进入项目工作台，内容分块，每块可以单独「重新生成 / AI 改写 / 手动编辑」：

| 区块 | 内容 |
|------|------|
| 基本信息 | 剧名（3 个候选）、类型、风格、市场、集数、一句话 logline |
| 故事梗概 | 300–800 字 |
| 世界观 / 背景 | — |
| 人物小传 | 主角、反派、关键配角：身份、动机、人设标签、人物弧光 |
| 人物关系 | 关系图（P1 可视化） |
| 核心冲突与爽点 | 主线冲突、爽点清单、名场面设计 |
| 节奏与付费建议 | 建议卡点位置（作为弹窗的默认值） |
| 结局方向 | 单结局，或互动剧的多结局方向 |

策划案确认后（点「下一步：生成集纲」）**自动弹出集纲生成弹窗**。

### 4.6 集纲生成弹窗（P0，重点交互）

```
┌──────────────── 生成集纲 ────────────────┐
│  ○ 直接生成全部集纲                        │
│     一次生成第 1–N 集，适合快速出整体       │
│                                            │
│  ● 分卡点输出集纲（推荐）                  │
│     按付费卡点分段生成，每段可单独精修      │
│                                            │
│   总集数 [ 80 ]                            │
│   1 ━━━━●━━━━━━━━━●━━━━━━━━━━━━●━━━━━ 80   │
│        一卡 12   二卡 35       三卡 60     │
│   一卡段 第1–12集(12) 二卡段 13–35(23)     │
│   三卡段 第36–60集(25) 结局段 61–80(20)    │
│   [一卡 − 12 +] [二卡 − 35 +] [三卡 − 60 +]│
│                                            │
│          [ 取消 ]      [ 开始生成 ]        │
└────────────────────────────────────────────┘
```

**卡点滑动交互规则**：
| 规则 | 说明 |
|------|------|
| 轨道 | 1 到 总集数 N，按整集吸附 |
| 默认值 | 来自策划案的「节奏与付费建议」；没有时按市场模板，比如国内 N=80 → 12 / 35 / 60【待确认】 |
| 约束 | 1 ≤ 一卡 < 二卡 < 三卡 ≤ N；相邻卡点间隔 ≥ 3 集【待确认】；拖动时不能越过相邻手柄，碰到边界停住并轻微震动或提示 |
| 精调 | 每个卡点有 −/+ 按钮，可直接输入数字；也支持键盘 ←/→ |
| 实时反馈 | 下方实时显示各段的集数区间和集数；改总集数时，卡点按比例缩放 |
| 结局段 | 三卡 < N 时，三卡之后到第 N 集为「结局段」，归在三卡之后一起输出【待确认：单独成段，还是合进三卡】 |

**生成后的跳转**：
- 选 ① → 进入「全部集纲」页。
- 选 ② → 左侧导航出现 **一卡 / 二卡 / 三卡**（+ 结局段）三四个入口，默认跳到「一卡」。
  - **生成顺序**：一卡段先生成。后续段依赖前一段的结尾来保证剧情连贯，所以前一段 `ready` 之前，后续段为 `blocked`（见 §5.4）。
  - 用户可以「一键依次生成全部段」，也可以一段一段确认、精修后再生成下一段。
- 卡点位置在生成后仍然可以调整。调整后，受影响的段及其下游会标记为 `outdated`，由用户决定是否重新生成。

### 4.7 集纲（P0）
每集一张卡片：
| 字段 | 说明 |
|------|------|
| 集号、标题 | — |
| 本集梗概 | 100–300 字 |
| 出场人物 / 场景 | — |
| 爽点 / 冲突点 | — |
| 结尾钩子 | 必填，卡点集的钩子要加强并高亮 |
| 卡点标记 | 一卡 / 二卡 / 三卡集显示💰标记 |

操作：单集重新生成、AI 改写、拖拽调整顺序、插入或删除集（总集数随之变化，卡点自动校正）、导出。

### 4.8 ⭐ 转互动影视剧本（P0，重点）

**入口**：全部集纲页，以及一卡、二卡、三卡每个段的页面，都有「转互动影视剧本」按钮。转换范围就是当前页的集数范围（全部或该段），也可以勾选部分集。

**转换配置弹窗**：
| 配置 | 选项 |
|------|------|
| 互动形式 | 选项分支（默认）/ 数值养成（好感度、属性）/ 限时选择（QTE）/ 混合 |
| 分支密度 | 低（每 3–5 集 1 个关键选择）/ 中（每集 1 个）/ 高（每集 2–3 个） |
| 分支收束策略 | 支线回主线（成本低）/ 多结局（2–5 个）/ 开放式 |
| 结局数 | 1–5 |
| 付费节点 | 是否把卡点映射为「付费解锁分支 / 结局」 |
| 视角 | 第一人称（玩家即主角）/ 第三人称 |
| Skill | 可挂「互动分支设计」等 Skill |

**互动剧本结构**（节点图）：
- **节点类型**：`scene` 剧情场景（台词 + 动作 + 镜头提示）、`choice` 选择点（2–4 个选项，带限时、条件、数值变化）、`condition` 条件判断（按数值或已解锁标记分流）、`ending` 结局（好 / 坏 / 隐藏 / 真结局）、`paywall` 付费点。
- **边**：选项 → 目标节点，可带条件和数值变化，比如「好感 +10」。
- **变量**：全局数值（好感度、金钱、声望…）、标记（是否见过某人…）。

**编辑器**：
- **画布视图**：节点和连线，支持拖拽、折叠集、按集分组泳道、小地图（参照 LibTV 画布、灵境交互）。
- **剧本视图**：线性阅读，选择点处展开各分支，方便编剧逐场精修。
- **预览模式**：在网页里「试玩」，逐个点选项走流程，显示当前变量值。
- **AI 操作**：给选择点追加选项、扩写某个分支、把多个支线收束到指定节点、为结局补写。

**结构校验**（导出前必须通过）：
| 校验项 | 级别 |
|-------|------|
| 存在无法到达的孤立节点 | 错误 |
| 存在死路（非结局节点没有出口） | 错误 |
| 某个结局不可达（条件永远不满足） | 错误 |
| 选择点只有 1 个选项 | 警告 |
| 某条路径时长与平均值偏差 > 50% | 警告 |
| 循环且没有退出条件 | 错误 |

**导出**：互动剧本 JSON（节点、边、变量，供播放器或引擎使用）、Excel 分支表、Word 或 PDF 拍摄剧本（按分支展开）。P1 对接分镜和视频生成。

### 4.9 通用能力
- **版本管理（P0）**：每次生成或重新生成都存一个版本，可对比、回滚。
- **上下游变更提示（P0）**：上游改动后，下游标记 `outdated`，见 §5.6。
- **生成中可离开（P0）**：任务在后台执行，完成后发站内通知。
- **额度（P0）**：按生成次数或字数扣减，失败的不扣。
- **评估（P1）**：参照泡漫的剧本评估，对策划案和集纲给出爆款潜力、节奏、爽点密度评分和改进建议。

### 4.10（暂定）爆款对标模式 —— 是否对齐麦芽
**建议：做，但放 P1。** 理由：
1. 短剧行业的主流做法本来就是对标爆款，需求真实，也是付费意愿最强的场景。
2. 可以复用已有链路：上传后先拆解，产出一份「对标策划案」，之后接原有的集纲 → 互动剧本流程，增量开发小。
3. 风险在版权和同质化，需要设计「结构借鉴、内容原创」的规则，以及相似度检测。

**流程**：上传爆款剧本或集纲 → **爆款拆解**（题材、人设模板、爽点节奏曲线、卡点位置、钩子手法）→ 选择方向：
- **本土化**：海外爆款改成国内版，替换文化背景、人物身份、价值观表达。
- **出海**：国内爆款改成指定海外市场版，按当地文化、禁忌、审美和节奏改写。
- **同构新创**：保留节奏结构，换题材和人设。

→ 生成新策划案（与原剧的相似度提示 < 阈值）→ 进入集纲弹窗。

## 5. 状态机定义（重点）

### 5.1 设计原则
- **两层状态**：「产物状态」描述文档本身，「任务状态」描述某次 AI 生成。一个产物可以对应多次任务。
- **上游变更要向下游传播**：策划案 → 集纲 → 互动剧本；上游内容一变，下游置为 `outdated`。
- 所有状态变化都写事件日志，便于排查和统计。

### 5.2 项目（Project）

| 状态 | 含义 | 进入条件 |
|------|------|---------|
| `draft` 草稿 | 已选模式和参数，还没生成 | 首页点「生成」前自动保存 |
| `parsing` 解析中 | 仅改编和对标模式：解析小说或爆款剧本 | 上传完成 |
| `parse_failed` 解析失败 | 文件损坏、格式不支持、超限 | 解析异常 |
| `planning` 策划阶段 | 策划案生成中或编辑中 | 开始生成策划案 |
| `outlining` 集纲阶段 | 已在弹窗中选择方式，集纲生成中或编辑中 | 弹窗点「开始生成」 |
| `interactive` 互动剧本阶段 | 至少一个互动剧本已创建 | 点「转互动影视剧本」 |
| `completed` 已完成 | 用户标记完成或已导出 | 手动操作 |
| `archived` 已归档 | 不在列表中显示，可恢复 | 手动操作 |

```
draft ─(原创)──────────────────→ planning → outlining → interactive → completed
  └─(改编/对标)→ parsing ─成功─↗      ↑           ↑            │
                    └─失败→ parse_failed ─重新上传→ parsing       │
（阶段可以回退：用户回到上一阶段编辑，项目阶段不倒退，下游标 outdated）
任意状态 ⇄ archived
```

项目阶段是「最远到达的阶段」，用于列表展示和进度条，不限制用户回头编辑。

### 5.3 生成任务（GenerationTask，通用）
适用于：解析、策划案、全部集纲、卡点段集纲、单集重生成、互动剧本转换、AI 改写。

| 状态 | 含义 |
|------|------|
| `queued` 排队中 | 已提交，等待资源 |
| `running` 生成中 | 流式输出，显示进度（比如「第 23/80 集」） |
| `succeeded` 成功 | 产物写入新版本 |
| `partial` 部分成功 | 批量任务中部分集失败，可以只重试失败的 |
| `failed` 失败 | 模型错误、超时、内容安全拦截（附原因码） |
| `cancelled` 已取消 | 用户取消，已生成的部分可保留为草稿 |

```
queued → running → succeeded
   │        ├────→ partial ─重试失败项→ queued
   │        ├────→ failed ─重试→ queued
   └────────┴────→ cancelled
```
- 同一个产物同时只能有一个 `running` 任务，再次点击时提示「正在生成，是否取消后重新生成」。
- `failed` 和 `cancelled` 不扣额度，`partial` 按成功的部分扣。

### 5.4 产物（Artifact：策划案 / 集纲 / 卡点段 / 互动剧本）

| 状态 | 含义 | 可编辑 | 可往下游流转 |
|------|------|-------|-------------|
| `empty` 未生成 | — | 否 | 否 |
| `blocked` 等待前置 | 前置产物未就绪（比如二卡要等一卡 `ready`） | 否 | 否 |
| `generating` 生成中 | 有任务处于 `running` | 否（只读流式查看） | 否 |
| `ready` 已生成 | AI 生成完成，未改动 | 是 | 是 |
| `edited` 已编辑 | 用户手动或用 AI 改过 | 是 | 是 |
| `outdated` 待更新 | 上游变了，内容可能不一致 | 是 | 是（需二次确认） |
| `locked` 已定稿 | 用户点「定稿」，防止误改；上游变化时只提示，不自动标 outdated | 否（解锁后可编辑） | 是 |
| `error` 生成失败 | 最近一次任务失败，而且没有可用的历史版本 | 否 | 否 |

```
empty ──开始生成──→ generating ──成功──→ ready ──编辑──→ edited
  ↑ (前置未就绪)         │失败(无历史版本)     │                │
blocked ─前置ready→ empty└──→ error ─重试──→ generating          │
                                               ↓ 上游变更        ↓
                                            outdated ←──────────┘
                                               │ 重新生成 → generating
                                               │ 忽略 → edited
ready / edited ⇄ locked（定稿 / 解锁）
```
- 有历史版本时重新生成失败：保持原状态，提示「生成失败，已保留上一版本」。

### 5.5 卡点段（OutlineSegment）专属规则

| 段 | 集数范围 | 前置依赖 |
|----|---------|---------|
| 一卡段 | 1 → 一卡 | 策划案 `ready / edited / locked` |
| 二卡段 | 一卡 + 1 → 二卡 | 一卡段 `ready / edited / locked` |
| 三卡段 | 二卡 + 1 → 三卡 | 二卡段 `ready / edited / locked` |
| 结局段 | 三卡 + 1 → N【待确认】 | 三卡段 `ready / edited / locked` |

- 前置未就绪 → 当前段为 `blocked`，导航上显示🔒和「请先完成一卡」。
- **调整卡点位置**：
  - 卡点后移（段变长）：本段要补生成新增的集，本段及后续段 → `outdated`。
  - 卡点前移（段变短）：被移出的集划给下一段，提示「是否保留这些集的内容」，后续段 → `outdated`。
  - `locked` 的段被卡点调整影响时，必须先解锁，否则不允许调整。
- **从「全部集纲」切到「分卡点」**（或反过来）：按卡点把已有集纲切分或合并，不重新生成，状态继承。

### 5.6 下游变更传播规则

| 触发 | 影响 |
|------|------|
| 策划案人物、主线、结局有改动（结构化字段变化，或正文 diff 超过阈值） | 所有集纲 → `outdated`（`locked` 的只提示） |
| 第 k 集集纲改动 | 第 k 集之后同段的集纲 → 提示可能不连贯（不强制）；覆盖第 k 集的互动剧本 → `outdated` |
| 卡点调整 | 见 §5.5 |
| 集纲 `outdated` | 由它转出的互动剧本 → `outdated` |

`outdated` 时页面顶部显示横幅：「上游已修改：[查看变化] [重新生成] [忽略]」。

### 5.7 互动剧本（InteractiveScript）
在 §5.4 产物状态之外，增加**结构校验状态**：

| 校验状态 | 含义 | 导出 |
|---------|------|-----|
| `unchecked` 未校验 | 编辑后自动变成这个状态 | 需先校验 |
| `checking` 校验中 | — | — |
| `valid` 通过 | 没有错误 | 可导出 |
| `warning` 有警告 | 只有警告 | 可导出（二次确认） |
| `invalid` 有错误 | 存在错误，逐条可定位到节点 | 不可导出 |

**节点级状态**（画布上用颜色标识）：`draft` 灰 / `generating` 蓝色闪烁 / `ready` 白 / `edited` 白色带角标 / `error` 红（校验错误）/ `warning` 黄 / `orphan` 虚线框（不可达）。

### 5.8 Skill

| 状态 | 含义 |
|------|------|
| `uploading` 上传中 | — |
| `validating` 校验中 | 格式、长度、安全审核 |
| `active` 可用 | 可以挂载 |
| `invalid` 校验失败 | 附原因 |
| `disabled` 已停用 | 用户停用；已挂载它的项目里会提示 |
| `pending_review` 公开审核中（P2） | — |

## 7. 异常与边界
| 场景 | 处理 |
|------|------|
| 一句话输入过短或无意义 | 小于 5 字时提示补充；给 3 个改写示例 |
| 小说解析失败 | 指明原因（编码、格式、超长），可以改成粘贴文本 |
| 内容安全拦截 | 任务 `failed`，原因码为「内容安全」，提示修改方向，不扣额度 |
| 生成中途刷新或关闭 | 任务在后台继续，回来后恢复进度 |
| 集纲生成集数和要求不一致 | 后端校验，缺的集自动补生成，状态为 `partial` |
| 卡点拖动越界 | 停在边界并提示约束 |
| 互动剧本节点数过多 | 单剧上限 2000 节点【待确认】，画布按集懒加载 |

## 8. 核心指标
| 指标 | 定义 |
|------|------|
| 策划案生成成功率 | succeeded / 提交 |
| 链路转化 | 策划案 → 集纲 → 互动剧本 各步转化率（**互动剧本转化率是重点**） |
| 弹窗选择分布 | 全部集纲 vs 分卡点；卡点默认值被修改的比例（用来校准默认模板） |
| 采纳率 | 生成内容被保留，未被重写超过 50% 的比例 |
| 重新生成率 | 单产物平均重新生成次数（越低说明质量越好） |
| Skill 使用率 | 精细生成中挂了 Skill 的比例；用户上传 Skill 数 |
| 导出率 | 项目导出数 / 项目数 |

## 9. 版本规划
| 阶段 | 范围 |
|------|------|
| **MVP** | 原创 + 小说改编双模式；一句话 / 精细生成；内置 Skill；策划案；集纲弹窗（全部 + 卡点滑动）；卡点段集纲；**转互动影视剧本（选项分支 + 多结局、画布 + 剧本双视图、校验、JSON / Excel 导出）**；完整状态机；版本管理 |

| **V1.2** | 团队协作和评论；Skill 共享市场；对接分镜和视频生成；多语言出海剧本 |
