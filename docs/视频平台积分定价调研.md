- 竞品普遍的口碑风险恰在这里：第三方评测称"积分消耗难预测"的工具排名明显下降；TapNow 有评测反映"显示 160 扣 96"这类展示与扣费不一致；小云雀有"积分消耗快于预期"的投诉；即梦 Seedance 2.0 上线后出现"涨价、排队、会员倒卖"的负面舆情。
- **建议：**生成页展示"选择参数 → 预计扣积分 → 约合人民币"，并标注优惠适用条件；扣费与展示必须一致；失败/审核拒绝全额返还并在账单可见。

### 🔴 3. P1｜大额购买权益面向工作室验证，不要直接降全模型价

- 按原稿，Looogen 充值档均为 ¥0.10/积分（无量大优惠）。
- 竞品做法并不一致：Vidu API 常规档**不**随充值额打折，而是靠活动包、错峰半价和商务方案；TapNow 国际站有"充值加赠，档位越高比例越高"；LibTV 年卡档位越高，月积分单价越低；可灵/即梦靠会员档位阶梯。
- **建议：**只在高档试 5% / 10% 加赠或阶梯合同价，配套并发、团队账户、发票、账单、专属服务；先测毛利、复购、批量客户转化，**不要**按 0.19 元/秒限时价下调全部模型。

### 🔴 4. P1｜免费体验要够完成一次有效生成

- 竞品免费额度的真实门槛差异大：Vidu 早期"注册 80 + 签到 20"与"注册 20 + 每日 5"两种说法并存；LibTV 称"首登 80 + 每日 20"；小云雀称"注册 1200 + 每日 120"；即梦称每日登录送积分（数额各来源不一致）。
- **建议：**先按"目标模型 × 最低可用时长"算出实际可生成条数，赠分低于一次完整生成就只会制造挫败。首登试用、每日赠分、邀请奖励**分池记录**，有效期和扣减顺序在账户页可见。

### 🔴 5. P1｜用"创作成果"换积分，而不是单纯换注册

- 即梦：创作者成长计划（作品积分＋周现金）、AIGC 推优、青年导演/短剧计划（积分＋保底金＋流量），层级完整。可灵：创作者计划 3.0、灵感值作品奖励、赛事奖金。LibTV：挑战赛、联名投稿。
- **建议：**先试"提交作品、审核通过后返还部分积分"，再加站外传播奖励、优质作品征集、项目合作。必须设：原创授权与版权授权、刷量防护、预算上限、到账时间。**拆解结构，不照搬金额。**

### 🔴 6. P2｜把"隐形跳价"显性化

- 若 H3 参考图"≤5 张 / ＞5 张"确有成本差异，在生成按钮旁展示触发条件、预计价格和加图增量，或改成明确的素材数量加价。

### 🔴 7. P2｜做邀请机制的反面教材要避开

- 可灵公开存在"填推荐码升级会员＋30%"一类**付费环节**激励；多数平台的邀请奖励数额公开信息很少。小云雀、TapNow 国际站本次**未找到公开邀请规则**。建议如做邀请，规则页写清：奖励对象（双方/单方）、触发节点（注册/首次生成/首次付费）、有效期、上限、反作弊。

### 🔴 需要你拍板的三个问题

1. Looogen 目标客户**优先个人创作者还是批量生产团队**（漫剧/短剧工作室）？
2. 各模型**完全成本与失败率**是多少？（决定折扣空间）
3. 付费积分、会员赠分、活动赠分**分别保留多久、扣减顺序如何**？（决定会计口径与客诉）

## 1. 研究口径与证据等级

| 等级 | 含义 |
|---|---|
| **A** | 官方定价/协议/活动页内容（含搜索引擎对官方页的摘要） |
| **B** | 原稿记录，本次官方页面需登录或动态加载，**未能复核** |
| **C** | 第三方媒体/评测/测评站，仅作线索，数字可能过期 |

**口径原则**
- 标价、会员价、按量充值价、活动价、API 价分别记录；积分"单价"只在**同一积分池**内有意义。
- 不能直接横比的例子：即梦的 Seedance 2.5 720p 限时低至 ¥0.43/秒（B）、LibTV 首页 ¥0.19/秒（B），均为活动展示，不代表长期成交价或相同权益。

**核心结论**
- 平台普遍是"**订阅权益 + 积分消耗 + 限时活动**"三件套，但**并非每家都"充值越多越便宜"**。Vidu API 常规档为固定积分汇率（B/A 部分印证），这否定了原稿"所有竞品量大优惠"的说法。
- 创作者激励已从"发积分"升级为**分层项目制**（积分 → 现金 → 流量/发行 → 保底金）。
- 价格体系普遍复杂且频繁变动，**"透明"本身已成为差异化点**。

## 4. 分平台详述

### 4.1 即梦（字节，消费端）

**收费结构**：会员 + 积分；会员分基础 / 标准 / 高级（及更高）。会员影响：月积分、Seedance 2.0 VIP 通道、队列、模型资格。
**可核验示例（A/C）**
- 官网展示（10/13–10/28 限时）：基础首年 ¥393（6 折）、标准首年 ¥1099（5.8 折）、高级所选档首年 ¥5199（5 折）。
- 原稿（B）：基础 725 积分/月、标准 2210/月、高级 12320/月。
- 免费积分来自**每日登录**；Seedance 2.0 VIP 专属通道仅对会员开放。
- 积分消耗（C，仅估算）：约 10 秒 60 积分、15 秒 90 积分；VIP 通道更高；Mini 5 秒约 45 积分。
- 原稿（B）：Seedance 2.5 720p 限时低至 ¥0.43/秒。
**舆情与风险**：Seedance 2.0 上线后出现"积分价格短期上涨、排队、会员倒卖、翻倍续费"等报道（C）；多篇称部分会员档位单条成本**已超过火山引擎 API（约 ¥1/秒）**——说明会员折扣并非总比 API 便宜。
**拉新**：原稿称邀请 188 积分（B，未复核）。本次搜索**未找到邀请奖励公开说明**。
**创作者激励（C，分层清晰，Looogen 最值得拆解）**

### 4.2 可灵（快手）

**消费端**：会员（灵感值）。官网列示（C）：黄金 660 / 铂金 3000 / 钻石 8000 / 黑金 26000 灵感值/月；黄金约 ¥5.99/7 天起（新客试用价、首购优惠，仅限一次）。2024 年上线时月卡 ¥66 / ¥266 / ¥666，对应 660 / 3000 / 8000，首发"5 折狂欢周"最低 ¥33。
**灵感值规则**：订阅期内按月发放，**月周期届满后清零**（C，知乎回答）。
**免费**：每日登录送灵感值（2024 为 66，约 6 个视频，次日重置；当前数额待核）。
**拉新**：官网页显示**"填推荐码升级会员 +30%"**——奖励绑定在付费环节而非注册。
**API / 企业**：采用**预付费资源包**，非纯按量；小额试用包约 $9.8（C）。消费端附加灵感值包 $5(330) 到 $200（C）。API 失败不扣费（C）。

### 4.3 Vidu（生数）

**消费端（C）**：标准 ¥69 / 800 积分（最多约 200 视频），专业 ¥259 / 4000，旗舰 ¥699 / 8000。免费：注册赠分＋每日签到，数额两版冲突。邀请：早期活动 500–1000 积分，已变动。官网有"创作者计划"入口，权益待核。

## 7. 会员模式与大客户
