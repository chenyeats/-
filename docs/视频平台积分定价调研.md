### 🔴 P0｜行业"元/秒"展示普遍是"带条件的最低价"，Looogen 要么跟进展示逻辑，要么用透明价做差异化

- 即梦团队版写"低至 ¥0.177/秒"，条件是**超级团队 12 个月**（每席 ¥22,932，最少 2 席即 ¥45,864）+ 带参考视频 5 折，活动只到 10-28。
- 小云雀写"个人版低至 ¥0.19/s，团队版低至 ¥0.177/s"，和即梦的数字完全一致。
- 可灵会员页写"720p 带视频参考低至 0.17 元/秒"，条件是**黑金会员 + Kling 4.0 限时 8 折**。

### 🔴 P0｜即梦示范了"短有效期换深折扣"：积分包打折，但有效期很短

| 积分包类型 | 有效期 | 折扣 | ¥/积分 |
|---|---|---|---|
| 日常补给包 | 2 年 | 无 | 0.100 |
| 月度包（每周限购 1 次） | 30 天 | 约 6.1 折 | 0.060 |
| 双周包 | 14 天 | 4–5.9 折 | 0.040–0.059 |
| 季度包（按金额阶梯） | 90 天 | 2.9–5.6 折 | 0.028–0.055 |

此外，所有积分包都**只卖给会员**，折扣越深要求的会员等级越高（4 折包只给超级会员）。这样既不冲击 2 年有效的常规价，又能让赶项目的团队一次性大量预付，过期未用的积分也减少了平台的实际算力成本。

<span style="color:red">**建议：**Looogen 的"量大优惠"可以直接借鉴这个结构：常规充值保持原价、长期有效；另设"14 天 / 30 天冲刺包"给 6–8 折，限会员或限购。先测试毛利和过期率，再决定折扣深度。</span>

### 🔴 P1｜创作者激励普遍是"赛事 + 分层计划 + 积分预算封顶"

- **可灵投稿赛（当前进行中两场）：**一等奖 12000 灵感值 + 单月钻石会员，二等奖 5800，三等奖 2200，参与奖 500。人气奖要求社媒自然流量达标（抖音 ≥4000 赞 / 小红书 ≥500 / 视频号 ≥300），送 500 元京东卡，三平台都达标再加 1000 元。
- **TapNow × MiniMax 赛事：**现金奖池 10 万元；另设 1000 个创作激励名额，**积分预算封顶 500 万**，分 A / B / C 三档，按"报名入选"和"有效投稿审核通过"两段发放。
- **Vidu Earn：**Rookie / Showcase / CPP 三层，分别对应邀请码与发布积分、社媒现金和积分、官方共创与分成。

<span style="color:red">**建议：**Looogen 的投稿返积分采用"两段发放（报名 → 审核通过）+ 总预算上限 + 同一自然人限领一次 + 刷量取消资格 + 投稿即授权宣传"。这几条可灵和 TapNow 的规则里都写明了，可以直接参考结构。</span>

### 🔴 P1｜会员权益差异化的重点是"并发、队列、错峰、无限卡"，而不只是积分

- **并发：**LibTV 标准 8 / 进阶 12 / 高级 20 / 豪华以上不限；TapNow Basic 4 / Pro 8 / Ultimate 起不限；可灵会员不限并发。
- **生成通道：**即梦全部会员都有 Seedance 2.0 VIP 专属通道，但只有高级、超级是"快速生成通道"，基础、标准是"标准生成通道"；Vidu 标准版是快速通道，专业、旗舰是极速通道。
- **错峰 / 闲时：**Vidu 专业版闲时 20 个视频/日、旗舰版 200 个/日；Vidu API 错峰价约为半价；TapNow Banana 2 每日 2:00–8:00 五折。
- **无限卡：**TapNow 按档位赠"Kling 4.0 无限用 1–30 天"；LibTV 有"免积分畅享卡"；海螺至臻 / 尊享会员可无限使用 Hailuo 模型。

<span style="color:red">**建议：**如果 Looogen 有算力峰谷差，优先测试"闲时额度 / 错峰半价"，比直接打折更不伤毛利。</span>

### 🔴 P2｜退款、保价、升级规则要提前写进页面

- **退款：**各家原则上都不退（TapNow、Vidu、LibTV、可灵都明确写了）。
- **保价：**LibTV 推出"会员权益 7 天保护计划"，7 天内同档位出现更高赠品可补发差额赠品；TapNow 承诺"营销活动价只要不断订就终身保留"。
- **升级：**LibTV、TapNow、可灵都公开了升级补差价公式。

<span style="color:red">**建议：**Looogen 上线会员前先写好"退款 / 升级 / 降级 / 到期"四条规则，FAQ 直接放在价格页底部。</span>

1. 目标客户优先个人创作者，还是短剧 / 漫剧批量生产团队？（决定是做首购低价，还是做团队席位和对公采购）
