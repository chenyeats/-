# 🧭 周末去哪儿 · 城市探索指南

面向大学生的周末活动推荐产品雏形：根据**偏好、天气、预算、人数**推荐本地活动，支持**组队出发、打卡记录、攻略分享**。

## 功能
- **发现**：首次进入 30 秒偏好引导；接入 Open-Meteo 实时周末天气；多因子打分推荐并给出“推荐理由/风险提示”；一键生成两天行程（控预算、控时长）
- **组队**：组队广场（差几人进度条）、加入/退出、发起组队、按日期筛选
- **打卡**：评分、心情、花费、照片上传；数据看板、活跃度热力图、成就徽章、城市探索进度；打卡一键转攻略
- **攻略**：最热/最省钱排序、点赞、“照着这篇去玩”一键收藏地点、发布攻略
- **我的**：偏好编辑、收藏、行程报备（安全）、产品设计说明

## 技术
纯静态 SPA（HTML + CSS + 原生 JS），无需构建，数据存储在 localStorage。

## 部署到 Vercel
在 Vercel 中 Import 本仓库，Framework Preset 选 **Other**，其余保持默认即可（无构建命令，输出目录为根目录）。
